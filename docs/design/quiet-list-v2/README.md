# Quiet List v2 — 승인된 시각 정본 자료

2026-11-05. 다섯 가지 탐색안 중 1안(잔여 목록, Quiet List)을 발전시킨 정제안으로, 오너가 선택한 방향.
정본 계약은 루트 `DESIGN.md`다. 이 폴더는 승인된 브라우저 목업 스크린샷의 보관소다.

## 파일

- `compact-v2-light.png`, `compact-v2-dark.png` — 최종 목업, 고정 데모 데이터(마스킹된 fixture),

## 주의

- 브라우저 목업은 정본이 아니다 — 디자인 탐색·커뮤니케이션용 일회성 자산이며 실제 제품은
  이 저장소의 네이티브 SwiftUI 구현이다. 목업의 DOM/JS는 배포물이 아니다.
- 스크린샷의 계정·수치·이메일은 모두 고정 데모 데이터다. 실제 계정·수집기·키체인 값이 아니다.
- 원본은 design_dev 작업 공간의 프로젝트에 남아 있고, 이 폴더에는 승인된 이미지만 복사했다.
- 변경 이력: 우선순위/링 게이지 → Quiet List v2 (잔여 비율 한 줄 한도, 두 줄 아이덴티티,
  환경·인증 배지 분리, 상세 보기 통일 라벨).
